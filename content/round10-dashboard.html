§ 02

The over-budget row

The real code clamps with Math.min(100, (spent / budgetLimit) * 100), so the bar physically cannot say how far past the line you went. That makes this the one row on the screen where the bar stops being the whole story — and it is also the row you feel something about. Three signals, none of them a coloured total: the bar runs to 100%, it hits an ink wall, and the overage is named in words.

§ Why not a red bar
  • 1The bar is a category, so it wears the category's colour. Repainting it red would break the one rule the whole screen rests on.
  • 2Six bars in six hues plus a seventh state hue is where the birthday-card dashboard starts.
  • 3Red bar and red text is one signal said twice. The wall is a different signal: it is shape, so it reads in greyscale, at a glance, and under any colour vision.
The wall is 7px of ink inside the clipped track
ConsideredWhy it is not here
Bar overflows the trackBreaks the panel's 1.5px boundary and makes six rows stop aligning. The clamp in the code is correct; the design should not fight it.
A second, darker segment past 100%Needs an unclamped percentage the component does not receive, and invents a second scale inside a bar that already has one.
Alert-tinted row backgroundA colour block behind live figures. Explicitly the failure mode.
A warning chip in the gutterThe gutter is the tether's. One gutter, one meaning — a warning glyph there would make provenance and state look like the same class of mark.
§ 03

State · loading

The shell is not data, so the shell does not wait: sidebar, wordmark, legend, nav and the date heading all render immediately. Only the four modules are skeletons. Column one of every skeleton row is a dashed circle at the chip's exact 30px and every bar keeps its real 16px track, so when the data lands nothing moves — the pulse stops and content appears in place. One keyframe, 1150ms, --ease-in-out, opacity .34 → .72, and it is the one thing removed outright under reduced motion.

§ 04

State · error

The dashboard fetches as one query, so it fails as one screen. The message is an ink-bordered notice that names the fix — never raw red text, never a full-page apology, never a shrug illustration. The only red on the surface is the 22px bang, which is a graphic, not a mood. The heading and the shell stay exactly where they were, because they never depended on the request.

§ 07

Mobile · 390 × 844

Position on the sidebar. It does not become a bottom tab bar — nine routes do not survive five slots, and picking five would silently demote four real parts of the product. It becomes a left sheet (shadcn Sheet) holding the same nine rows in the same order, opened from a 44px control, 320ms on --ease-drawer, scrim rgba(26,26,26,.34) with no blur. The chip legend goes with it, because on a 390px screen the legend is a thing you consult once, not furniture you live beside.

Position on the 108px figure. ₹16,415 at 108px is 455px wide and does not fit in a 354px column, and 108 has no neighbour on the locked scale. So Guilt-Free steps to --type-figure-2 52px and Net Worth steps with it, down to --type-h2 26px in mono. 52 : 26 is a 2.0× ratio against the desktop's 2.08× — the hierarchy is preserved by moving both rungs, not by shrinking one and letting them converge.

§ 08

Motion on this screen

Seven entries. Four of them deliberately animate nothing. Every position below was approved at the round-7 gate and is reproduced here as built, not re-argued.

ElementMotionReduced motion
Net WorthCount-up, 600ms, power4.out, once per session. The sole carve-out to rule 12. Formatted through Intl on every frame so the lakh/crore commas are correct mid-count, never a raw integer that regroups when it lands.Disabled entirely — the final value is set synchronously.

§ 09

Implementation

What an engineer actually writes in web/app/dashboard/. Nothing below contains a hex value, a bezier, or a bare pixel radius — those all come from docs/design/brand-kit/tokens.css via the Tailwind preset.

01 · Net worth · the sole rule-12 carve-out 
// components/dashboard/NetWorth.tsx
'use client';
import { useRef } from 'react';
import { useGSAP } from '@gsap/react';
import gsap from 'gsap';

const inr = new Intl.NumberFormat('en-IN', {
  style: 'currency', currency: 'INR', maximumFractionDigits: 0,
});

const SEEN = 'sorted:netWorthCounted';

export function NetWorth({ value }: { value: number }) {
  const el = useRef<HTMLParagraphElement>(null);

  useGSAP(() => {
    // Once per session. Not once per mount — TanStack refetches, route
    // changes and Fast Refresh must never replay it.
    if (sessionStorage.getItem(SEEN)) return;

    const mm = gsap.matchMedia();
    mm.add('(prefers-reduced-motion: no-preference)', () => {
      const o = { v: 0 };
      gsap.to(o, {
        v: value,
        duration: 0.6,                 // the approved cap, not a target
        ease: 'power4.out',          // === --ease-out
        // Format every frame. A raw integer counting up and then
        // suddenly growing two commas is worse than no animation.
        onUpdate() { el.current!.textContent = inr.format(Math.round(o.v)); },
        onComplete() { el.current!.textContent = inr.format(value); },
      });
    });
    sessionStorage.setItem(SEEN, '1');
    return () => mm.revert();
  }, { dependencies: [value], scope: el });

  // Server-rendered final value. If JS never runs, this is already right.
  return <p ref={el} className="fig-1 tabular-nums">{inr.format(value)}</p>;
}

06 · Pre-ship guards for this file
  • viewBoxgrep '<svg><use' returns zero. Every one of the wrappers on this screen carries viewBox="0 0 24 24"; the sprite host carries none because it renders nothing.
  • FocusNo outline:none anywhere except inside prose. Every ring is outline: var(--focus-ring); outline-offset: var(--focus-offset), drawn outward onto cream at 11.77:1 — never inset, never box-shadow-as-ring on the ink-filled pill.
  • PressNo scale() in any :active block. The stamp presses by translateY(2px) with the shadow collapsed, both properties on one 110ms --ease-out.
  • ShadowExactly one box-shadow declaration lineage in the file, and it is the stamp. No blur, no spread, no backdrop-blur.
  • Text tokensEvery string containing a verb is --dim-2 at 5.71:1. --dim appears only on uppercase mono micro-labels.
